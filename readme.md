# System Design Lab

A collection of system design resources covering high-level architecture, low-level design patterns, and AI-powered design agents.

## Repository Structure

```
system-design-lab/
├── system_design_agents/    # Claude Code agent plugins for system design tasks
│   └── agents/
│       └── plugins/         # 72 specialized agent plugins
└── (more sections coming soon)
```

## System Design Agents

Pre-built Claude Code agent plugins sourced from [wshobson/agents](https://github.com/wshobson/agents), covering:

| Category | Plugins |
|----------|---------|
| **Architecture** | C4 Architecture, Cloud Infrastructure, Deployment Strategies, Kubernetes Operations |
| **Backend** | Backend Development, API Scaffolding, Database Design, Database Migrations, Data Engineering |
| **Frontend & Mobile** | UI Design, Frontend Mobile Development, Multi-Platform Apps |
| **DevOps & CI/CD** | CI/CD Automation, Observability & Monitoring, Incident Response, Deployment Validation |
| **Security** | Backend API Security, Frontend Mobile Security, Security Compliance, Security Scanning |
| **Testing & Quality** | Unit Testing, TDD Workflows, Performance Testing, Code Review, Code Refactoring |
| **AI/ML** | LLM Application Dev, Machine Learning Ops, Agent Orchestration |
| **Languages** | Python, JavaScript/TypeScript, JVM Languages, Julia, .NET, Systems Programming, Shell Scripting |
| **Business & Analytics** | Business Analytics, Startup Business Analyst, Quantitative Trading, SEO, Content Marketing |
| **Other** | Game Development, Blockchain/Web3, Payment Processing, Reverse Engineering |
